# Stock Valuation Monitor 落地规则（xyy）

## 使用边界
1. 仅用于**盘后估值体检**。
2. 不作为盘中唯一交易依据。

## 风控规则（强制）
- 若返回结果包含“数据不足”或“单源数据（仅1个数据源）”，结论一律标记为：**仅观察，不交易**。
- 需至少满足以下条件才可进入“可参考”状态：
  - 返回状态为 success；
  - 非“数据不足”；
  - 数据源数量 >= 2。

## 推荐流程（盘后）
1. 运行估值检查脚本（支持多代码）。
2. 读取每只标的的 zone / sources / action。
3. 仅对 action=REVIEW 的标的做次日候选；action=OBSERVE 的标的不下交易指令。
