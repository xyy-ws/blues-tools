## 数据流说明

```
① 日志产生          各安全设备/系统产生原始日志
        ↓
② 采集归一化        Vector Agent 采集 → 统一字段格式
        ↓
③ 关联分析          SIEM 规则引擎 → 多源日志 → 复合告警
        ↓
④ 告警分级          P0/P1/P2/P3/P4 分级
        ↓
⑤ SOAR 研判        接收 → 去重 → 剧本 → 审批/执行 → AI辅助
        ↓                ↓
⑥ 工单创建          自动从告警生成 TheHive 工单
        ↓
⑦ 调查闭环          分配 → 处置 → 验证 → 关闭
        ↓
⑧ 指标统计          MTTD / MTTR / 处置率 / 闭环率
```
